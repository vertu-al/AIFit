# Chapter 7 — Action and Active Generalized Filtering

## Overview

Chapter 7 introduces one of the central ideas of Active Inference:

> Perception changes beliefs to better explain sensory observations, whereas action changes the world so that observations become consistent with the agent's preferred states.

Unlike classical control theory, Active Inference does not separate perception and action into independent processes. Both are driven by the same objective: reducing prediction error and, ultimately, variational free energy.

AIFit implements these ideas through a simplified Bayesian thermostat that reproduces the qualitative dynamics described in Chapter 7.

# Theoretical Background

Active Inference assumes that an agent never observes the true state of the world directly.

Instead, it receives noisy sensory observations and must infer the hidden causes that generated them.

```text
Hidden State
      ↓
Observation
      ↓
Inference
      ↓
Belief
```

Perception updates hidden-state beliefs.

Action changes the environment.

Together they reduce prediction error.

---

# The Bayesian Thermostat

The first AIFit example models a one-dimensional thermal environment.

The hidden state is the agent's position.

```text
Position
      ↓
Temperature
      ↓
Observation
```

The agent cannot observe position directly.

Instead, it observes temperature and infers where it must be located.

The agent also possesses a preferred temperature.

When perception alone is insufficient to explain observations, action changes the environment until observations approach the preferred sensory state.

# Mathematics

## Hidden State

\[
x^*
\]

The true (hidden) environmental state.

---

## Belief

\[
\mu_x
\]

The agent's posterior belief about the hidden state.

---

## Observation

\[
y
\]

Sensory input generated by the environment.

---

## Prediction

\[
g(\mu_x)
\]

Predicted sensory observation generated by the agent's internal model.

---

## Sensory Prediction Error

\[
\varepsilon_y
=
y-g(\mu_x)
\]

Difference between observed and predicted sensations.

---

## Preference Error

\[
\varepsilon_p
=
y_{\mathrm{preferred}}-y
\]

Difference between the preferred and observed sensory state.

---

## Action

\[
a
\]

Action changes the environment so that future observations better match the preferred sensory state.

---

## Free Energy

The current implementation uses a pedagogical free-energy proxy consisting of precision-weighted sensory and preference prediction errors.

Future chapters will replace this proxy with the complete variational free-energy objective.

# Action–Perception Loop

Each simulation step follows the same sequence.

```text
Observe

↓

Compute prediction error

↓

Update belief

↓

Update action

↓

Change environment

↓

Repeat
```

This closely follows the algorithm presented in Chapter 7.

---

# Results

The simulation produces three complementary views of Active Inference.

## Hidden State

Compares the true hidden state with the inferred belief.

Initially the belief is incorrect.

Perception gradually aligns belief with reality.

---

## Sensory Space

Compares observations with predicted observations.

As prediction error decreases, predictions become increasingly accurate.

---

## Action and Free Energy

Action becomes active after an initial period of perception-only inference.

Once action is enabled, the environment itself changes.

Free energy decreases as observations approach the preferred sensory state.

---

# Interpretation

The simulation illustrates several important principles.

- Hidden states are never directly observed.
- Perception updates beliefs.
- Action changes the environment.
- Prediction errors drive both processes.
- Active Inference minimizes surprise through a continuous perception–action cycle.

Although intentionally simple, this model captures the essential qualitative behaviour of Chapter 7.

---

# Current Limitations

The present implementation is educational rather than mathematically complete.

In particular, it currently omits

- generalized coordinates
- expected free energy
- policy selection
- hierarchical generative models
- full variational free-energy minimization

These extensions will be introduced in later chapters.

# What We Learned

Chapter 7 demonstrates that Active Inference is not simply perception and not simply control.

Perception and action are two complementary processes driven by the same objective.

Perception changes internal beliefs.

Action changes the external world.

Together they reduce prediction error and maintain preferred states.
