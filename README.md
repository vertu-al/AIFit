# AIFit

An educational Active Inference framework implemented in Python.

Inspired by

> Fundamentals of Active Inference:
> Principles, Algorithms and Applications of the Free Energy Principle

AIFit recreates the examples from the book while providing
well-documented, reproducible Python implementations.

## Current Progress

- Chapter 7
    - Bayesian Thermostat
    - Active Generalized Filtering
    - Perception
    - Action
    - Free Energy
